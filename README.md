# Pi 5 price tracker
1. Create a free GitHub account and a new public repository (e.g. pi5-prices).
2. Upload everything in this folder, keeping the structure (scripts/, .github/workflows/, index.html, prices.json).
3. Settings > Pages > Deploy from branch: main, folder: / (root). Your site appears at https://YOUR-NAME.github.io/pi5-prices/
4. Actions tab > "Daily price update" > Run workflow (first run). After that it runs every night at 00:00 Tunisia time.
Add more comparison pages to SOURCES in scripts/update_prices.py to search more shops.
